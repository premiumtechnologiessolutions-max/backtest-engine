# Plan-scoped independently pinned M1 risk in historical monthly scorecard — 2026-10-28

The read-only `scripts.research_batch_monthly_scorecard` now accepts **optional, independently frozen** M1 evidence pins and replays the strict `research_equity_m1_audit.audit_equity` verifier before showing any observed floating risk. Previously unpinned results remain **N/A**. No new backtests or broker executions are performed.

## Offline usage

```sh
python -m scripts.research_batch_monthly_scorecard --plan /private/frozen-plan.json --out /private/batch --equity-pins /private/equity-pins.json
```

The optional private JSON pins file must be created and independently preserved **before** a later audit. Schema:

```json
{
  "schema": "NRFX_EQUITY_PINS_V1",
  "plan_sha256": "<64 lowercase hex>",
  "source_sha256": "<64 lowercase hex>",
  "engine_commit": "<40 lowercase hex>",
  "jobs": {
    "my-frozen-job": {
      "summary.json": "<64 lowercase hex>",
      "monthly.csv": "<64 lowercase hex>",
      "equity_m1.csv": "<64 lowercase hex>"
    }
  }
}
```

The verifier rechecks the original private ZIP hash, exact clean Git checkout, frozen batch manifest, canonical summary/weekly/monthly/trade ledger, and all three pinned files. For each pinned run, every observed UTC month and M1 sample count must match the exit-booked monthly ledger. The **global running equity peak** carries between months, with each month's maximum observed M1 peak-to-trough drawdown and gap-event count recorded separately from exit-booked monthly P/L. No missing minute is fabricated, and no standalone strategies are combined into a shared-capacity portfolio.

**Security/provenance limitation:** a pin file generated by hashing the same potentially tampered evidence at audit time is *not* independent attestation. The operator must freeze and retain the original hashes through an independently auditable channel at execution time. The scorecard validates pinned bytes but cannot prove when or by whom pins were originally recorded. Missing pins stay null/N/A; invalid, stale, unknown-job, or mismatched pins fail closed. Existing legacy runs are not retroactively certified.

No original private Gold ZIP was loaded in this code change; no new historical monthly P/L or clean prospective OOS was produced. No raw BID/ASK data, live MT5 connection, billing changes, or merge. PR #1 stays Draft.
