# NO RISK FX — Quant Lab Desktop V1

## ماذا يعمل فعلياً؟

واجهة عربية محلية للبحث الكمي، تعمل على جهازك فقط. من الواجهة تستطيع ربط **أرشيف الذهب الأصلي SHA256**، اختيار سنة تاريخية واستراتيجية، توليد شبكة تجارب، معاينة عددها، تثبيت خطة لا يمكن تعديلها، تشغيل 1–20 باكتيست بكل دفعة، استكمال الدفعة، واستعراض صفقات التنفيذ والنتائج الشهرية. زر تدقيق الأدلة يعيد قراءة المصدر الأصلي ويتأكد من نسخة Git وتطابق سجلات الصفقات والتقارير. زر Cross-Year يستدعي مقارنة تدريب/مراجعة بعد اكتمال بيانات البحث المطلوبة، ويرفض ترتيب المرشحين إذا كان جزء من العائلة غير منفذ.

**هيدي منصة أبحاث تشغيلية أولية V1، وليست منتجاً نهائياً مستضافاً أو منصة تداول مباشر.** البحث التاريخي المعروض ليس اختبار OOS مستقل، ولا توجد استراتيجية مثبتة ربحيتها أو ضمان ربح كل شهر.

## التشغيل على Windows

- فكّ ضغط الحزمة بمجلد مستقل **خارج** مستودع Git.
- شغّل `start_quantlab_windows.bat` (يتطلب Git for Windows وPython 3.12 مثبتَين، واتصالاً بالإنترنت لأول تثبيت). السكريبت يستنسخ الفرع المحدد من مستودع المشروع، وينشئ بيئة Python مستقلة، ويثبّت الاعتماديات محلياً. لا يحمّل بيانات الذهب الخام ولا يغيّر إعدادات GitHub أو الفوترة.
- يفتح متصفحاً على `127.0.0.1:8766` برمز جلسة محلي. اختر مسار أرشيفك الأصلي `Gold data.zip` من داخل الواجهة.
- **لا تفك ضغط ملف الذهب أو ترفعه إلى GitHub.** الباكتيست يقرأ الـZIP في مكانه فقط.
- أنشئ خطة صغيرة أولاً (تجربة واحدة) وثبّتها، ثم اضغط Start Research. لاحقاً استخدم زر Research Universe لإنشاء التعريفات المتعددة السنوات من دون تشغيلها فوراً. زر Re-audit يعيد المطابقة قبل الاعتماد.

لم يتم اختبار ملف BAT على Windows فعلي في هذه الجلسة؛ إصلاح القفل متوفر على الفرع، لكن قبول نسخة Windows النهائية يتطلب تشغيل اختبار end-to-end على Windows/Python 3.12.

## تشغيل Linux/macOS

استخدم `./start_quantlab_linux.sh` على Linux؛ تحتاج Python 3.12 وgit. على macOS استخدم التثبيت اليدوي مع تثبيت الحزم المطلوبة وتشغيل `python start_quantlab.py --engine-repo /absolute/path/to/backtest-engine --open`.

## ملاحظات هندسية

- أحدث Git commit مطلوب **نظيف**. تشغيل واجهة محلية من خارج Git يمنع إضافة ملفات غير متتبّعة داخل `src/` أو `scripts/`، التي كانت ستمنع تثبيت البحث.
- مصدر المستخدم يجب أن يطابق SHA256: `1163474d1419212f1ebd199fb77f8dd6b3029040488f0b7180218fd339159121`.
- التكلفة الثابتة **$0.40/oz all-in**، من غير إضافة Spread وهمي ثانية.
- لا يوجد اتصال وسطاء أو تداول حي. الـAPI لا يقبل إلا loopback `127.0.0.1`، مع رموز جلسة محلية ورفض الطلبات من أصول أخرى.
- قاعدة الباكتيست تعيد التنفيذ من بيانات المستخدم، وتكتب تقارير `trades.csv`, `monthly.csv`, `weekly.csv`, `summary.json` وتدقيق SHA256؛ الخطط مجمّدة ومتطابقة مع نسخة Git.
- لا يوجد تشغيل تلقائي في الخلفية بعد إغلاق التطبيق؛ التشغيل يحتاج إبقاء الكمبيوتر والخدمة شغّالين. عند إغلاق التطبيق أثناء دفعة يمكن استعادة التقارير المكتملة، أما النتائج الجزئية غير المكتملة فتُرفض حتى تحقق يدوي.
- بعض الاستراتيجيات ما زالت في نطاق البحث والتقييم؛ واجهة V1 تعرض النتائج ولا تدّعي الربحية.

## ما الذي يتطلبه إصدار نهائي أقوى؟

1. اختبار Windows حقيقي مع نفس اعتماديات التشغيل، وGitHub CI على آخر commit.
2. نموذج عمل لخطة أبحاث متعددة السنوات مع توزيع تجارب، أرشفة immutable، وإحصاءات تعدد الاختبارات.
3. تصنيف المرشحين على عينات لم تُستخدم في الاختيار، ثم اختبار prospective حقيقي.
4. واجهة أوسع لعائلات استراتيجيات جديدة وتحرير قواعد البحث المركّبة.
5. نشر آمن اختياري مع تسجيل دخول وصلاحيات، إذا تقرر استخدامه من أكثر من جهاز؛ النسخة الحالية **محلية فقط**.

## فحص عملي مُنجز في بيئة التطوير

في Linux/Python 3.13: نجحت 160 حالة اختبار موجّهة (المحرك الأصلي + التطبيق، ومنها 31 اختباراً للواجهة والتحكم). شغّل التطبيق الجديد سنة 2012 على المصدر الحقيقي في دفعة واحدة EMA/M15: **670 صفقة، -$261.34140073 للأونصة، شهر رابح واحد من 12**، وتحققت حالة `RE_AUDITED_HISTORICAL_EXPOSED_NOT_OOS` للتجربة المكتملة وظهرت بيانات الأشهر. نتيجة سلبية، لا تصلح للتداول.

المخرجات التفصيلية لذلك التشغيل الحقيقي محفوظة **محلياً خارج هذه الحزمة** في مساحة العمل الخاصة، ولا يدمج ZIP بيانات الصفقات أو أسعار المستخدم حتى لا ينشر معلومات تجارته أو مصدره.
