# NRF-FAC-001 — 20,000 distinct parameter variants, 40,000 real-source annual replays

Research date: 2026-10-26. This file records a **correlated parameter-grid exploratory search**, not 20,000 independent trading hypotheses.

## Frozen experiment construction
- Code: [scripts/batch_donchian_grid.py](../scripts/batch_donchian_grid.py), frozen on branch at commit `006529841afeb519594be14885f448c9f53699b0`.
- Original private `Gold data.zip` SHA-256 `1163474d1419212f1ebd199fb77f8dd6b3029040488f0b7180218fd339159121`; raw M1 **not uploaded**.
- Years individually evaluated: **2012** (352,975 real XAUUSD M1 observations), **2013** (352,317 real M1 observations). Yearly position forced close/account restarts; the sum is NOT a continuously managed portfolio.
- Native **M15 Donchian close-confirmed breakout** at entry trigger; vary lookback **5–24 inclusive** (20), stop USD/oz **1–13 by 0.50** (25), target USD/oz **1–20.50 by 0.50** (40). **Exactly 20 × 25 × 40 = 20,000 configurations.**
- Each variant: 1 ounce, one position, next available M1 open within 1 minute of fully closed signal; reference BID-OHLC synthetic quote, stop-first ambiguous M1 bars, adverse open gaps fill beyond stop; sole $0.40 round-trip ALL-IN per ounce. No added spread or commission.
- Numba JIT accelerates an *event-driven replay* sharing the original yearly M1 arrays and the 20 native lookback signal sets; no changing exit rules. At first/middle/last parameter settings, the full original **run_fast()** was executed on the same original ZIP and compared for complete 12-month settled net, trade counts, fees, net and **maximum minute-marked floating drawdown**; all **six parity samples matched to 1e-7**. This validates these tested samples, not all 40,000 trade ledgers individually.
- Public GitHub Actions [run #40382642257](https://github.com/premiumtechnologiessolutions-max/backtest-engine/actions/runs/40382642257): full suite **596 passed** in Python 3.12. The exact CI source artifact was re-executed locally with the private source ZIP for both 20k-year cohorts.

## Required controls to expand this to hundreds of thousands and new algorithm families

1. Generate **new causally defined hypothesis families** (e.g., RSI mean reversion, trend/volatility regime conditioned entries, closing-range rejection). Hash the family and parameter spec before reading outcome data.
2. Use a **two-stage run**: high-throughput synthetic BID-OHLC exploratory screening over private data; then canonical execution replay and full *shared-capacity* portfolio run for every proposed composite — sum of separate ledgers is **not** a portfolio.
3. Record per-month settled and observed-floating equity, max DD, fees, trade count, worst month, and number of months with observed market data. Reject poor performers; no retroactive tweaking under the same hypothesis ID.
4. Enforce walk-forward splits and multiple-testing penalties: 20,000 correlated parameter choices are a severe overfitting/false-discovery risk. Years 2012–2013 are already exposed in the wider research program; they are NOT clean OOS. An unobserved future evaluation period is necessary.
5. The private original archive remains outside public CI. A scheduled task can periodically start research where authorized data/runtime access exists; it does **not** magically create an always-running private-data cloud machine.

**Research decision:** No 12/12 winner. This particular Donchian M15 parameter family does not meet the target. Do not label an annual-positive member a proven or live-ready strategy. Private full 40k annual/monthly ledgers and reproducible source snapshot are retained outside public GitHub as `NoRiskFX_Factory_40000_Historical_Backtests_2026-10-26.zip`.
